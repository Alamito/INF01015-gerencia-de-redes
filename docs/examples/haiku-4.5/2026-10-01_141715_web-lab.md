# Incidente: web-lab

_2026-10-01 14:17:15_

### Resumo
Falha no web-lab foi causada pelo serviço estar indisponível. Investigação confirmou conectividade do host, mas porta 8080 fechada. Serviço foi reiniciado com sucesso e agora responde normalmente.

### Evidências
- Ping 127.0.0.1: 0% packet loss, latência 1ms — host alcançável
- check_port 127.0.0.1:8080 (antes): estado "closed", connection refused
- restart_service "web": sucesso, serviço iniciado
- check_port 127.0.0.1:8080 (depois): estado "open", latência 0.5ms
- check_http http://127.0.0.1:8080/: HTTP 200 OK, latência 6ms

### Causa provável
Falha do serviço web (crash, parada inesperada ou timeout). O host estava alcançável, eliminando problemas de rede ou DNS. A porta 8080 não escutava conexões, confirmando que o processo estava parado.

### Ação tomada
Reinicio do serviço lab "web" via `restart_service`. Confirmação pós-remedição demonstra operação normal: porta aberta e aplicação respondendo com status HTTP 200.

### Recomendação
Investigar logs do serviço web para identificar causa raiz do crash. Implementar monitoramento de processo e alertas de reinicio automático para evitar indisponibilidade prolongada.
